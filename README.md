🐾 PawCare – Pet Care Management Application

PawCare is a mobile application developed using Kodular for helping pet owners manage pet care activities efficiently. The app allows users to manage pet profiles, reminders, vaccinations, deworming schedules, mood tracking, and personalized pet care tips.

✨ Features
1.Pet Profile Management

2.Feeding & Medicine Reminders

3.Vaccination Tracking

4.Deworming Schedule

5.Dynamic Pet Care Tips

5.Mood Interaction System

6.TinyDB Local Storage

🛠 Technologies Used
1.Kodular

2.TinyDB

3.Android Platform

4.Event-driven Programming
